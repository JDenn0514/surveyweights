# GSS 2024 sample data with harmonized demographic columns

The 2024 General Social Survey (GSS), obtained from
[`surveycore::gss_2024`](https://jdenn0514.github.io/surveycore/reference/gss_2024.html).
All 3,309 respondents are retained, including those with `NA` in `sex`
or `age`. The raw integer `sex` column is overwritten in-place with a
factor. Five derived columns are added: `age_f3` (factor from `age`),
`race_f4` (factor from `race` and `hispanic`), `pid_f3` (factor from
`partyid`), `edu_f3` (factor from `degree`), and `wt_pop`
(population-scaled weight for IPW use).

To construct a survey design for standard estimation, use:

    data(gss_2024)
    gss_design <- surveycore::as_survey(
      gss_2024, weights = wtssps, strata = vstrat, ids = vpsu, nest = TRUE
    )

For IPW workflows, use the `wt_pop` column instead of `wtssps`:

    ref <- surveycore::as_survey(
      gss_2024, weights = wt_pop, strata = vstrat, ids = vpsu, nest = TRUE
    )
    ipw(ns_wave1, ref, selection = ~sex + age_f3)

## Usage

``` r
gss_2024
```

## Format

### `gss_2024`

A data frame with 3,309 rows and 32 columns. All 27 original columns
from
[`surveycore::gss_2024`](https://jdenn0514.github.io/surveycore/reference/gss_2024.html)
are retained. The `sex` column is overwritten in-place as a factor; five
new derived columns are added:

- vpsu:

  Numeric. Primary sampling unit identifier for variance estimation.

- vstrat:

  Numeric. Stratum identifier for variance estimation.

- wtssps:

  Numeric. GSS normalized weight (mean approximately 1). Use for
  standard survey estimation. For IPW use `wt_pop` instead.

- wtssnrps:

  Numeric. Alternative GSS weight (non-response adjusted).

- ballot:

  Numeric. GSS ballot form assigned to the respondent.

- year:

  Numeric. Survey year (2024).

- id:

  Numeric. Respondent identifier.

- age:

  Numeric. Age in years. Some respondents have `NA`.

- sex:

  Factor. Derived from the original integer `sex` column: `1` =
  `"Male"`, `2` = `"Female"`, `NA` for other values. Levels:
  `c("Male", "Female")`.

- race:

  Numeric. Race: `1` = White, `2` = Black, `3` = Other.

- hispanic:

  Numeric. Hispanic origin indicator.

- educ:

  Numeric. Years of education.

- degree:

  Numeric. Highest degree: `0` = Less than HS, `1` = HS, `2` = Some
  college, `3` = College, `4` = Graduate.

- income16:

  Numeric. Total family income (categorical).

- marital:

  Numeric. Marital status.

- wrkstat:

  Numeric. Labor force status.

- hrs1:

  Numeric. Hours worked per week in primary job.

- adults:

  Numeric. Number of adults in household.

- partyid:

  Numeric. Party identification (7-point scale).

- polviews:

  Numeric. Political views (7-point scale).

- happy:

  Numeric. General happiness.

- health:

  Numeric. Self-rated health.

- trust:

  Numeric. Social trust.

- natfare:

  Numeric. Opinion on welfare spending.

- abany:

  Numeric. Abortion opinion (any reason).

- attend:

  Numeric. Religious service attendance frequency.

- relig:

  Numeric. Religion.

- age_f3:

  Factor. Derived from `age` using
  `cut(age, breaks = c(18, 35, 55, Inf), right = FALSE)`. Levels:
  `c("18-34", "35-54", "55+")`. `NA` for age \< 18 or missing age.

- race_f4:

  Factor. Derived from `race` and `hispanic`: Hispanic origin takes
  precedence (`hispanic > 1` = `"Hispanic"`); `race == 1` = `"White"`,
  `race == 2` = `"Black"`, else `"Other"`. Levels:
  `c("White", "Black", "Hispanic", "Other")`.

- pid_f3:

  Factor. Derived from `partyid`: `0:2` = `"Democrat"`, `3` =
  `"Independent"`, `4:6` = `"Republican"`, `7` = `NA`. Levels:
  `c("Republican", "Independent", "Democrat")`.

- edu_f3:

  Factor. Derived from `degree`: `0` = `"Less than HS"`, `1:2` =
  `"HS/Some college"`, `3:4` = `"College+"`. Levels:
  `c("Less than HS", "HS/Some college", "College+")`.

- wt_pop:

  Numeric. Population-scaled weight:
  `wtssps * (260000000 / nrow(gss_2024))`. Use for IPW reference design
  construction (sums to approximately 260 million, the 2024 US adult
  population estimate).
